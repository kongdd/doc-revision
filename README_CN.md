# Code Diff Tracker

以类似 Word 的修订模式审阅当前文件中尚未暂存的 Git 变更。

## 使用

1. 打开已提交过的 Git 仓库及其中已纳入暂存区的文件。
2. 在左侧“修订”面板或状态栏开启修订；快捷键为 macOS `Shift+Option+G`，Windows/Linux `Shift+Alt+G`。
3. 点击修订，使用提示窗口中的箭头切换，或在左侧选择上一处、下一处。
4. **Accept** 将所选修订暂存到 Git 暂存区；**Reject** 在编辑器中撤销所选修订，保存后才写入文件。

已暂存的修改不再显示。修改行背景色默认关闭，可在左侧面板开启；文字修订标记不受影响。

## 注意事项

- 需要启用 VS Code 内置 Git 扩展；尚未纳入暂存区的新文件暂不支持。
- 文件大小限制为 1 MiB。删除文字是编辑器虚拟文本，不能直接选择或复制。
- 原录制审阅功能已移除，旧录制数据不会被主动删除，但本版本不再读取或展示。

## 开发

```sh
npm install
npm test
npm run lint
npm run package
```
