# Document Revision

以类似 Word 的修订模式审阅当前文件中尚未暂存的 Git 变更。

## 使用

1. 打开已提交过的 Git 仓库及其中已纳入暂存区的文件。
2. 在左侧“修订”面板开启修订；快捷键为 macOS `Shift+Option+G`，Windows/Linux `Shift+Alt+G`。
3. 点击修订，使用提示窗口中的箭头切换，或在左侧选择上一处、下一处。
4. **Accept** 将所选修订暂存到 Git 暂存区；**Reject** 在编辑器中撤销所选修订，保存后才写入文件。也可在“修订导航”中选择**全部接受**或**全部拒绝**，操作仅针对当前文件，执行前需确认；选中若干行后，可在“修订导航”中选择**接受选中行**或**拒绝选中行**，仅处理选区内的修订，不扩展到相邻修改行；删除块归属其前一行（文件开头的删除归属首行）。
5. 在删除文字的修订提示中，可选择并复制部分原文。

选择 **Show Unstaged** 审阅未暂存修改，或选择 **Show All Changes** 显示相对 HEAD 的净修改。已暂存修订的 Accept 不可用，Reject 同时丢弃暂存区和磁盘中的所选修改。暂存与未暂存修改同时存在时，Accept 暂存所选修订；Reject 在编辑器中撤销，并同步撤销暂存区中已有的该修订；若无法安全同步暂存区，则提示冲突，不修改正文或暂存区。

面板开关保存在当前工作区文件夹的 `.vscode/settings.json`，下次打开时自动恢复。修改行背景色默认关闭；文字修订标记不受影响。

## 注意事项

- 需要启用 VS Code 内置 Git 扩展；尚未纳入暂存区的新文件暂不支持。Show All Changes 暂不支持 HEAD 中不存在的文件。暂存后又在工作区反向撤销的修改因净差异为零，不会显示。
- 纯换行符格式（CRLF/LF）及末尾换行变化不单独显示为修订。
- 文件大小限制为 1 MiB。正文中的删除文字是虚拟文本，请在修订提示中选择并复制。
- 原录制审阅功能已移除，旧录制数据不会被主动删除，但本版本不再读取或展示。
